# Itihasika — redesign prototype (demo build)

**Live demo:** https://manthriudaykiran.github.io/itihasika-demo/

This repository contains only the **built static files** of a UX redesign prototype for three pages of itihasika.com (About Us, Books, ABC Activity Book of Indian History). It is a design demo, **not the live Itihasika store**: "Buy" links open the real Amazon or Gumroad pages, and other site links open the current itihasika.com.

The source code is kept in a separate private repository. Pages are marked `noindex`.
